## 3. Database Schema (`packages/db/src/schema.ts`)
- Ids: `text` PK = `crypto.randomUUID()` unless noted. Every table has `createdAt timestamptz default now()`; all timestamps timestamptz.
- `vector(384)`: `vector('name', { dimensions: 384 })` from `drizzle-orm/pg-core`.
- Auth tables: generated by Better Auth CLI into `packages/db/src/auth-schema.ts` (T5), re-exported from `schema.ts`; do not
  hand-write. `admin` plugin adds `user.role/banned/banReason/banExpires`, `session.impersonatedBy`.

```
provider       id, name text unique, baseUrl text (https only), apiKeyEncrypted text,
               extraBody jsonb default '{}' (merged into every chat request body), enabled bool default true
author         id, providerId->provider, slug unique, displayName, modelId, bio null,
               color text default '#64748b' (/^#[0-9a-f]{6}$/i), temperature real default 0.7,
               maxOutputTokens int default 4000, enabled bool default true
feed           id, name, outlet, url unique, enabled bool default true, lastFetchedAt null, lastError null
raw_article    id, feedId->feed, outlet, url unique (normalized), title, excerpt, content null,
               publishedAt, embedding vector(384) null, eventId->event null
media          id, rawArticleId->raw_article, kind 'image'|'video'|'youtube',
               url (https file URL, or 11-char id for youtube), posterUrl null, caption null; UNIQUE(rawArticleId,url)
event          id, title, centroid vector(384), articleCount int 0, outletCount int 0,
               status 'open'|'queued'|'generated'|'skipped' default 'open', queuedAt null, firstSeenAt, lastSeenAt
source_packet  id, eventId->event unique, articleIds text[], payload jsonb, contentHash
prompt_template id, version int unique, system, user, active bool default false
generation_run id, authorId->author, packetId->source_packet, promptVersion int,
               status 'pending'|'running'|'succeeded'|'failed'|'invalid', latencyMs, tokensIn, tokensOut,
               rawOutput, error, finishedAt (all null); UNIQUE(authorId,packetId)
post           id, runId->generation_run unique, eventId->event, authorId->author, slug unique, headline, dek,
               bodyMarkdown, wordCount, publishedAt, like/dislike/comment/favorite/shareCount int 0,
               citationValidRatio real, paragraphCitationRatio real, linkCount 0, mediaCount 0,
               unknownRefCount 0 (links/media not in packet), formatViolationCount 0 (see 4)
post_citation  postId->post, index int, rawArticleId->raw_article; PK(postId,index)
reaction       userId->user, postId->post, value smallint (1 like, -1 dislike); PK(userId,postId)
favorite       userId->user, postId->post; PK(userId,postId)
comment        id, postId->post, userId->user, parentId->comment null, body, hidden bool default false
share          id, postId->post, userId null, ipHash null, channel 'copy'|'x'|'reddit'|'email'|'native'
```
**Indexes:** `raw_article(publishedAt)`, `raw_article(eventId)`, `media(rawArticleId)`, `event(status,lastSeenAt)`,
`post(eventId)`, `post(authorId)`, `comment(postId)`, `generation_run(status)`,
`index('event_centroid_idx').using('hnsw', t.centroid.op('vector_cosine_ops'))`.

**Count columns** on `post` are caches: any change to reactions/favorites/comments (incl. hide/unhide)/shares recomputes the
count with `SELECT count(*)` in the same transaction. Never increment blindly.
